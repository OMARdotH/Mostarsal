# مِداد — مكتبة عربية رقمية

واجهة مكتبة كتب عربية تعمل على GitHub Pages، مبنية بـ HTML + CSS + JavaScript فقط.

## المزايا

- واجهة RTL عربية بالكامل.
- خط Cairo مناسب للواجهة العربية.
- شريط كتب أفقي في الصفحة الرئيسية.
- الكتاب الأوسط أكبر وأكثر وضوحًا.
- غلاف الكتاب الأوسط يظهر كخلفية ضبابية.
- الأسهم للتنقل + أسهم لوحة المفاتيح + السحب على الهاتف.
- انتقالات ناعمة بطابع Apple-esque.
- صفحة تفاصيل مستقلة لكل كتاب.
- مكتبة مع بحث وتصفية حسب التصنيف.
- تصميم متجاوب للهواتف.
- دعم `prefers-reduced-motion`.
- لا توجد حاجة إلى قاعدة بيانات في النسخة الأولى.

## تشغيل محلي

يمكن فتح `index.html` مباشرة في المتصفح، أو تشغيل خادم محلي بسيط.

## النشر على GitHub Pages

1. أنشئ مستودع GitHub جديدًا.
2. ارفع جميع الملفات والمجلدات.
3. من:
   `Settings → Pages`
4. اختر:
   `Deploy from a branch`
5. اختر فرع `main` ومجلد `/ (root)`.
6. احفظ وانتظر بناء الموقع.

## إضافة كتاب

افتح `js/books.js` وأضف عنصرًا جديدًا إلى مصفوفة `books`.

ثم:
1. ضع صورة الغلاف في `assets/covers/`.
2. ضع ملف PDF في `books/`.
3. حدّث `cover` و`download`.
4. عدّل العنوان والمؤلف والوصف والتصنيف.

## ملاحظة

الملفات الموجودة في `books/` هنا مجرد مكان مخصص للملفات. لم تتم إضافة كتب محمية بحقوق النشر. استخدم فقط كتبًا تملك حق توزيعها أو كتبًا ضمن الملكية العامة.
